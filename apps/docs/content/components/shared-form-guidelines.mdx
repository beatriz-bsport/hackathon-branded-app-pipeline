## Overview

Every form control shares label, control, mandatory indicator, and helper text patterns.

##### Shared Elements

All form controls include the following elements:

1. _Label_
   A descriptive text that explains the purpose of the form control. Labels are essential for accessibility, providing context for the control, and should be concise yet informative.
2. _Control_
   The interactive element of the form, such as a checkbox, radio button, toggle, text field, select, or text area. This is where the user directly interacts with the form.
3. _Mandatory Indicator_
   An asterisk (\*) or other visual cue placed next to the label to indicate that the field is required. It helps users identify which fields they must complete before submitting the form.
4. _Helper Text_
   Optional text placed below the control that offers additional guidance or clarifies what is expected from the user. Helper text should be brief and supportive, helping users avoid errors.
