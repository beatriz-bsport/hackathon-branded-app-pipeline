# Navigation sidebar application

This application contains the business logic for the navigation sidebar.

It is meant to be imported using module federation into other applications.

- 📚 [bsport Microfrontend Quickstart Guide](https://www.notion.so/bright-shovel-41b/Quickstart-Create-a-Micro-Frontend-17e137e4c6408017880efb0d5548df17)

## Standalone mode

You can run the app in standalone mode for local development using:

```sh
pnpm dev
```

## Federated mode

If you want to use the app in federation locally, you can use:

```sh
pnpm build:preview
pnpm preview
```

Then run your desired application.
