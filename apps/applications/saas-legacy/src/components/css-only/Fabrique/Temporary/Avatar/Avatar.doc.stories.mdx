# Avatar

## Description

The `Avatar` component displays a user's profile picture in different sizes. It allows customization of the picture, size, and additional styling.

## Properties
- **picture:** The picture's path you want to use for your avatar.
- **size:** **`sm`** (small), **`md`** (medium), **`lg`** (large)
- **type:** Will define the default picture used as placeholder **`user`** (User), **`place`** (Place)
- **className:** Override or extend the styles applied to the component.
