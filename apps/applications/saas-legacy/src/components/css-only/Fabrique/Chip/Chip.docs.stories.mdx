# Chip

## Description
The **`chip`** component is a small container used to display contextual information. It is designed to be visually distinct and can be used for a variety of purposes, including tags, filters, or statuses.

#### Usage
The **`color`** property distinguishes different types of chips, providing visual cues to users. Removable chips typically include a close button, allowing users to remove selected items or preferences.
