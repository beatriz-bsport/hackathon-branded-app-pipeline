Kaizen is the React design system powering the Back Office and the rest of
bsport's back-office surfaces. These docs are a living reference — authored as MDX,
deployed continuously, and built to be readable by both humans and large
language models.

## What's inside

- Two-level navigation: top tabs scope the docs to one area; the sidebar lists
  that area's pages.
- Live examples powered by embedded Storybook stories — the same stories
  used by engineering, side by side with the docs.
- Auto-generated props tables and token references straight from source.
- A `.md` companion for every page, plus
  [`/llms.txt`](/llms.txt) and [`/llms-full.txt`](/llms-full.txt) so LLMs can
  ingest the whole system in one request.
