# Card

## Description

The **`card`** component serves as a versatile container, allowing you to present various types of content in a structured and visually appealing manner. Within the card, you can include different children components referred to as card content. Cards are commonly used to display information, images, or actions in a compact and organised format. They provide a consistent and user-friendly way to showcase content, making it easy for users to scan and interact with the displayed information.

## Usage

Cards are ideal for displaying items such as articles, products, user profiles, or any other type of content that benefits from a structured presentation.

Customise the content, layout, and styling of the card based on the specific use case and design requirements of your application.

The component can contain various children components, referred to as card content, allowing flexibility in designing the content inside the card.

### Rest

#### Usage
The rest variant of the card component represents the default state of a card. It is designed to display regular content without any special emphasis. This variant provides a clean and neutral appearance, suitable for displaying general information or items
