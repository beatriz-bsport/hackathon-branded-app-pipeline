## Overview

Badges add compact supplementary metadata inline with content. They modify — they do not stand alone.

#### Color

| Color      | Description                                                |
| ---------- | ---------------------------------------------------------- |
| `default`  | Used for subtle visual emphasis.                           |
| `main`     | Used for key information.                                  |
| `critical` | High-visibility colour for urgent or critical information. |
| `custom`   |                                                            |

#### Has icon

| Value  | Description                                                                       |
| ------ | --------------------------------------------------------------------------------- |
| `true` | Badges can include an icon alongside text or numbers for context and recognition. |

### Usage Guidelines
