# Button

## Description

Acting as a `popover`, the `menu` component provides a user interface for displaying a list of options and actions.

The menu can be opened on hover or on click depending on its function.

`menu` usually displays 3 tips of items: textItem, checkbox or radio.

The menu and menu items can be navigated using keyboard controls.

### Positioning

Can be positioned according to its anchor element (generally the button responsible for its opening).

It can be customized thanks to the properties `anchorOriginHorizontal`, `anchorOriginVertical`, `transformOriginHorizontal` and `transformOriginVertical` 
Some positions are showcased below but you can even use number values to precisely set positions.
