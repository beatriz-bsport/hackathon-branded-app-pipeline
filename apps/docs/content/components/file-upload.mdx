## Overview

File upload handles selecting files via browse or drag-and-drop, previewing images,
and tracking upload progress. Use it for pass covers, member documents, and import
templates — wire to your API layer for `autoUpload` or fully controlled flows.

## Guidelines

<DoDont>
  <Do caption="List accepted formats and max size in helper text before users browse." />
  <Do caption="Show upload progress or success when `autoUpload` is enabled." />
  <Dont caption="Silent failure when file exceeds limit — always message." />
  <Dont caption="Drag-only upload without a visible browse button." />
</DoDont>
