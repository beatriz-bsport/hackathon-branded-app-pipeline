# Settings | Teacher View | Studio Manager Application

## Quickstart

### Run locally

```sh
pnpm run dev
```

This starts:

- the Navigation Sidebar on port `4050`
- `@bsport/sm-teacher-view` on port `4060`

Open <http://localhost:4060>.

### Build translations

```sh
pnpm run translation:update
```

### Build for preview

```sh
pnpm run build:preview
```

### Build for production

```sh
pnpm run build
```
