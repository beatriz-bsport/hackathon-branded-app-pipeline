## Overview

Flexible data table for presenting, comparing, and acting on multi-column records in Studio Manager

Table displays structured data in rows and columns. It supports typed column rendering (dates, prices, avatars, custom cells), optional row selection, pagination, loading and empty states, and row-level navigation. Use it when users need to scan or compare several attributes per record — anywhere column alignment beats a [List](/components/list) layout.

### Use cases

- **Entity directory** — multiple attributes per row; optional row link to a detail view.
- **In-place comparison** — dense multi-column data where the table is the destination.
- **Bulk actions** — checkbox selection with header select-all for batch operations.
- **Activity history** — paginated read-only log with datetime columns.
- **Formatted values** — locale-aware dates, numbers, prices, and optional sign coloring.

For narrow containers or single-column scanning, prefer [List](/components/list). See [Use of tables and lists](/patterns/tables-and-lists) for index table vs data table intent.

## Guidelines

<Callout type="warning" title="Caution">

Table does not collapse columns on narrow viewports. Wide tables scroll horizontally; on mobile, reduce column count or switch to [List](/components/list).

</Callout>

<DoDont>
  <Do caption="Match each column's type to its data format so dates, prices, and numbers render with consistent locale formatting." />
  <Do caption="Provide loadingProps and emptyStateProps — users should see a Loader or EmptyState, not a blank area." />
  <Do caption="Add paginationProps when the dataset exceeds one screenful, with a default page size of 10." />
  <Dont caption="Interactive controls inside a row that already has a row link create nested focus targets — stop propagation on in-row buttons and links." />
  <Dont caption="Large row height in dense grids with many rows forces excessive scrolling — reserve lg for content-rich rows." />
  <Dont caption="A redundant View action button alongside a row link — the row itself already navigates." />
</DoDont>

### Selection

<DoDont>
  <Do caption="Pair selectable tables with a bulk action bar driven by checkedIds." />
  <Dont caption="Row checkboxes without a visible bulk action — selection state feels orphaned." />
</DoDont>

<Callout type="warning" title="Caution">

Kaizen does not ship a bulk action bar yet. When using `selectable`, build the bar in product code and wire it to `checkedIds`.

</Callout>

### Row navigation

<DoDont>
  <Do caption="Use row.link for index tables where clicking a row opens a detail view — member list to member profile." />
  <Dont caption="Row links on data tables where users analyze values in place — the table is the destination, not a launcher." />
</DoDont>

### Row height

<DoDont>
  <Do caption="Keep sm as the default for dense operational tables — bookings, transactions, logs." />
  <Dont caption="lg in tables with dozens of rows — it reduces visible records without improving scannability." />
</DoDont>

### Content rules

Keep column headers short and scannable. Put explanatory detail in tooltips, page copy, or cell content — not in header labels that wrap inside compact rows.

Write empty and search-empty copy in second person, present tense, with a clear next step.

**Empty dataset**

> No email templates yet. Create one to start contacting your members.

**Empty search**

> No results found. Clear filters to see more members.

**Loading**

> Loading members…

### Column configuration

Each column in `columns` requires `id`, `header`, and `type`. Supported types:

- **string** — plain text from `keyPath`.
- **number** — locale-formatted number from `keyPath`.
- **price** — currency via `getCurrencyDisplayWithPrice`; optional `priceColoring` for positive/negative values.
- **date** / **datetime** / **time** — locale-formatted temporal values from `keyPath`.
- **avatar** — Avatar from `keyPath` (string URL or `{ src, alt }`); optional `size`.
- **copy** — CopyToClipboard button for `keyPath` value.
- **custom** — `render(row)` for arbitrary React content.
- **link** — declared in types but not rendered by the component today (use `custom` or row-level `link` instead).

Shared column options: `align` (`start` \| `center` \| `end`), `cellsClassName`, `colClassName` (column width).

Row-level fields on `BaseRow`: `id` (required), `link`, `color`, `className`, `onRowClick`, `isActive`.

### Behaviors

#### Row links and clicks

When `row.link` is set, the row is wrapped in a native `<a>` — the full row is clickable for navigation. When only `onRowClick` is set, the row uses a click handler on a `div` without link semantics. In-row buttons must call `stopPropagation()` (and `preventDefault()` on links) to avoid triggering row navigation.

#### Loading state

When `loadingProps.isLoading` is true, the entire Table (header and rows) is replaced by a centered Loader and optional message.

#### Empty state

When `emptyStateProps.isEmptySearch` is true (with `emptySearchConfig`), a no-results EmptyState renders instead of the table. When `isEmpty` is true (with `emptyConfig`), a classic empty state renders. Empty search takes precedence over empty.

#### Pagination

When `paginationProps` is provided, a [Pagination](/components/pagination) bar renders below the table. The parent fetches and passes the correct page slice in `rows`; Table does not paginate internally.

#### Responsiveness

Table does not auto-collapse columns. Long cell content can push columns off-screen — constrain width with `colClassName` or `cellsClassName` (e.g. `truncate max-w-[…]`). The container allows horizontal scroll.

### Edge cases

- **Empty columns / rows with empty state off** — renders an empty table shell with header only.
- **Very long text** — cells use `whitespace-nowrap` by default; add `cellsClassName` truncation or max-width on string/custom columns.
- **Negative price/number values** — `price` shows minus sign; apply `priceColoring` when sign should carry semantic color.
- **Multiple selection state** — one CheckboxProvider per Table instance; selection applies to currently rendered rows only (current page when paginated).
- **hideHeader** — header row omitted; selection column still renders when selectable is true.

## Accessibility

### ARIA roles & attributes

The root container is a `<div>` with `role="table"` and `aria-labelledby="table"`. The body uses `role="rowgroup"`. Rows and cells use CSS `display: table-*` on `<div>` elements rather than native `<table>` markup.

Kaizen sets `role="table"` and `aria-labelledby="table"` on the root. Provide a visible page or section heading with `id="table"` so the accessible name resolves — typically the view title above the table.

Checkboxes use the [Checkbox](/components/checkbox) component with per-row `id` values. The select-all checkbox uses `id="select-all"`.

Rows with only `onRowClick` (no `link`) are not keyboard-operable — prefer `row.link` for navigable rows.

### Screen reader behavior

Header cell text is announced when navigating by row/cell in supporting browsers. Checkbox state (checked, unchecked, indeterminate on select-all) follows Checkbox semantics. Locale-formatted dates, numbers, and prices are read as visible text.

Row color indicators are visual only — do not rely on color alone; pair with text or chips in a status column.

### Focus management

Table does not trap focus. When a row link navigates away, focus moves per browser default. After bulk actions, return focus to a logical control (e.g. the bulk action bar) in product code.

### WCAG criteria

- **1.4.3 Contrast (Minimum)** — text and borders use design-system surface and stroke tokens.
- **1.4.1 Use of Color** — pair `row.color` and `priceColoring` with explicit labels or status text.
- **2.1.1 Keyboard** — checkboxes, links, and in-row buttons are operable; `onRowClick`-only rows are a gap.
- **4.1.2 Name, Role, Value** — table role is set; pair with a heading `id="table"` for the accessible name.
- **4.1.3 Status Messages** — loading and empty states use separate components; table data updates are not live-region announced by default.

#### Implementation gaps

- **Loading replaces entire table** — when `loadingProps.isLoading` is true, header and rows are unmounted; only the Loader shows. Docs previously implied the header stayed visible.
- **`link` column type not rendered** — `ColumnType` includes `link`, but `TableRow` has no handler; use `custom` or `row.link`.
- **`onRowClick` without `link`** — mouse-only; no keyboard activation or button role.
- **`copy` column ignores `tooltip` / `toastMessage`** — column config accepts these props but `TableRow` does not pass them to CopyToClipboard.
- **`disabledIds` not forwarded** — `CheckboxProviderProps` includes `disabledIds`, but Table does not pass it to CheckboxProvider.

#### Design or API debt

- **Div-based table layout** — CSS table display on divs instead of semantic `<table>` markup; audit when hardening accessibility.
