## Overview

Toggle button looks like [Button](/components/button) but retains a pressed selected
state. Reserve it for **dense, horizontal controls** on surfaces operators touch
often — display-settings popovers, filter buttons, table cells — where choices should
flip instantly without a form submit.

Prefer vertical [Checkbox](/components/checkbox) and [Radio](/components/radio)
lists for classic forms, [Toggle](/components/toggle) for slower boolean settings,
and [Segmented control](/components/segmented-control) for connected view-mode bars.

### Use cases

- **Multi-select buttons** — several independent toggles in a row; multiple can stay
  on (column pickers, day selectors, optional filters).
- **Exclusive choice** — one active option among a few; parent deselects the others.
- **Per-row state** — binary on/off for one item inside a table cell or list row.

### When not to use

- Legal consent, destructive confirmation, or options that need helper text per row.
- Connected view-mode bars (_List_ / _Grid_, _Day_ / _Week_) — use
  [Segmented control](/components/segmented-control).

## Guidelines

### Patterns

| Pattern              | Layout                     | Check icon                 | Alternative                                                       |
| -------------------- | -------------------------- | -------------------------- | ----------------------------------------------------------------- |
| Multi-select buttons | Horizontal, dense, instant | Show `check` when selected | [Checkbox](/components/checkbox) group in forms                   |
| Exclusive choice     | Horizontal, dense, instant | None — selected fill only  | [Segmented control](/components/segmented-control) for view modes |
| Per-row on/off       | Table or list cell         | None — label or fill       | [Toggle](/components/toggle) in forms                             |

<DoDont>
  <Do caption="Add check icon on selected multi-select buttons; omit it for exclusive choices." />
  <Do caption="Use aria-pressed so screen readers announce toggled state." />
  <Do caption="Use Segmented control for 2–4 exclusive view modes in one bar." />
  <Dont caption="Toggle button for submit actions — use Button intent call-to-action." />
  <Dont caption="Check icon on exclusive options — selected fill is enough." />
  <Dont caption="Vertical checkbox lists when horizontal buttons would be faster." />
</DoDont>

### Edge cases

- **Disabled while selected** — show selected styling and explain disable reason nearby.
- **Exclusive group** — only one selected; manage at parent like radio behavior.

## Accessibility

### ARIA roles & attributes

Use `aria-pressed="true|false"` on the button element.

### Keyboard navigation

<Accessibility
  keyboard={[
    { keys: ["Tab"], description: "Focuses each toggle in the toolbar." },

  ]}
/>

### Screen reader behavior

Announces label and selection (via `aria-pressed`) on focus.

### Focus management

Focus stays on control after toggle.

### WCAG criteria

- **2.1.1 Keyboard** — toggle without pointer.
- **4.1.2 Name, Role, Value** — selected state exposed programmatically via `aria-pressed`.
