## Overview

Time picker captures hours and minutes for class start times, booking windows,
and reminder schedules. Pair it with [Date picker](/components/date-picker) when
both date and time matter, and respect studio timezone in displayed values.

### Use cases

- **Class start time** — session editor in booking module.
- **Reminder offset** — send notification X minutes before start.
- **Opening hours** — venue availability end time.
- **Staff shift blocks** — coarse time selection in scheduling tools.
- **Filter by time** — narrow list results to morning sessions.

## Guidelines

<DoDont>
  <Do caption="Combine with date picker when scheduling absolute moments." />
  <Do caption="Use consistent minute increments across booking and calendar views." />
  <Do caption="Validate that end time is after start time at form level." />
  <Dont caption="Free typing without mask when picker enforces valid slots." />
  <Dont caption="Sub-minute precision unless product requires it." />
  <Dont caption="Local time without indicating timezone on cross-region studios." />
  <Do caption="24h vs 12h — follow locale conventions configured for the studio." />
  <Do caption="Minute steps — align increments with scheduling granularity (5, 15 minutes)." />
  <Do caption="Disable past times — on same-day bookings when combined with today's date." />
  <Do caption='Label clearly — "Start time" vs ambiguous "Time".' />
  <Do caption="Timezone context — show studio timezone in helper when users work remotely." />
</DoDont>
