## Overview

Divider is a decorative line between blocks of content. It carries no semantics,
labels, or interaction. It most often separates form sections,
panel blocks, or filter groups — not individual table rows or menu items.

Reach for spacing tokens first. Add a divider when the boundary still feels
unclear after gap utilities.

## Guidelines

<DoDont>
  <Do caption="Separate logically distinct form or panel sections — session settings, filter cards, drawer blocks." />
  <Do caption="Tune spacing with className — my-xl between form steps, my-0 inside tight lists." />
  <Dont caption="Table row lines — use Table withHorizontalDivider instead." />
  <Dont caption="Menu or sidebar groups — use Menu divider items or NavigationMenu.Divider." />
  <Dont caption="Stack multiple dividers with only a few pixels between them — one rule plus spacing is enough." />
</DoDont>

## Reference

### Props

<PropsTable component="Divider" />

Horizontal dividers span the container width. Vertical dividers need a parent
with defined height — rare in Studio Manager product code; Kaizen uses them in
header action clusters and pagination.

The component renders a decorative `span` with no ARIA role. Section structure
must come from headings or landmarks — not from the divider itself.
