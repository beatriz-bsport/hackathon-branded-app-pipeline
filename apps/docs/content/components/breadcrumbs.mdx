## Overview

Breadcrumbs help users understand where they are and navigate back up the hierarchy.

### Properties

- _active (boolean):_ Indicates if the breadcrumb item represents the current page.
- _collapsed (boolean):_ If true, and there are too many items to fit, the breadcrumb will collapse into `…` button and is accessible through a dropdown menu showing additional items.

### Structure

- _Container:_ Encloses the breadcrumb trail.
- _Breadcrumb Items:_ Links or icons representing each level of the hierarchy.
- _Separator:_ A right-chevron used to separate breadcrumb items.

### Related Components

- _Dropdown Menu:_ Used for showing additional breadcrumb items when collapsed.
- _Breadcrumb item:_ Individual items within the breadcrumb trail.
