## Overview

Chips carry semantic meaning, can be dismissed, and often appear in groups as tags, filters, or statuses.

### Variants

- _Weak:_ Subtle style with lighter emphasis.
- _Strong:_ Bold style with stronger visual emphasis.

#### Size

- _sm:_ 24px height, suitable for use inside Dense forms.
- _lg:_ 32px height, used as the default density.

#### Colour

- `default` and `main` are used as main colours for tags.
- Status colours are used for status messages.
- `custom` is used for colours set-up by users.

##### Related Components

- _Badge:_ A component similar in size but often used for status indicators.
