## Overview

Collapse provides context and subcomponents (`Controller`, `Content`) to build
expandable regions. Unlike [Accordion](/components/accordion), it is compositional —
you control the trigger UI and placement. Use it for optional detail blocks,
filter panels, and custom disclosure patterns.

### Use cases

- **Advanced filters** — reveal secondary filter fields behind "More filters".
- **Inline help** — expand guidance under a form section title.
- **Nested detail** — show line-item breakdown under a summary row.
- **Custom accordion** — when [Accordion](/components/accordion) header chrome is too rigid.
- **Self-toggle content** — controller rendered inside content for "Show less" links.

## Guidelines

- **Controller owns toggle** — use `Collapse.Controller` render prop for `isOpen` and `toggle`.
- **Initially closed by default** — expand only when users need the content immediately.
- **Animate with care** — ~200ms transition; avoid collapsing primary actions.
- **Id for a11y** — pass `id` when wiring `aria-controls` from custom triggers.
- **Do not hide required fields** — required inputs must be visible or clearly marked in the header.

### Best practices

#### General

<DoDont>
  <Do caption="Label the controller with clear show/hide text or an icon plus visible text." />

### Behaviors

#### Dismissal

Toggle via controller; no automatic close on outside click.

#### Persistence

Internal state resets on remount unless controlled from parent.

### Edge cases

- **Controller inside content** — supported pattern for reciprocal hide links.
- **Computed children** — dynamic content height animates after layout settle.

## Accessibility

### ARIA roles & attributes

Wire `aria-expanded` and `aria-controls` on custom triggers to the content `id`
when you do not use Accordion's built-in header.

### Keyboard navigation

### Screen reader behavior

Announce expanded/collapsed state on the trigger, not on every inner field.

### Focus management

When collapsing, avoid trapping focus inside hidden content — disable tab stops or unmount.

### WCAG criteria

- **2.1.1 Keyboard** — controller must be keyboard operable.
- **4.1.2 Name, Role, Value** — trigger has accessible name.
