## Overview

Icon renders a named glyph from the Kaizen icon library at a consistent size.
Icons annotate buttons, list rows, alerts, and navigation items — they rarely
stand alone without a text label unless the meaning is universal (close, search,
chevron).

### Use cases

- **Button prefixes** — `iconLeft` on [Button](/components/button) for save, add, export.
- **Alert and toast status** — paired with severity copy in [Alert](/components/alert).
- **List row metadata** — leading icon for item type in buyables or finance lists.
- **Navigation chevrons** — disclosure and expand affordances in menus and collapse.
- **Empty states** — large decorative icon while [Illustration](/components/illustration)
  is preferred for marketing-style empties.

## Guidelines

- **Label beats icon alone** — pair with visible text except for universally understood glyphs.
- **Size matches touch target** — use `md` beside body text; `sm`/`xs` only in dense tables.
- **Color carries meaning sparingly** — default inherits `currentColor`; semantic colors
  belong on status components, not every icon.
- **One metaphor per action** — do not swap icons for the same action across one flow.
- **Valid names only** — invalid `icon` values log an error and render nothing.

### Best practices

#### General

<DoDont>
  <Do caption="Pair icons with button labels so the action is clear without hover." />
  <Do caption="Use the same icon for the same action across Studio Manager modules." />
  <Do caption="Inherit text color so icons respect disabled and hover states on parents." />
  <Dont caption="Color-only icons to signal errors — pair with text or Alert status." />
  <Dont caption="Decorative icons on every row when spacing already groups content." />
  <Dont caption="Inventing ad-hoc SVGs outside the library fragments the product visual language." />
</DoDont>

### Content rules

Icons do not contain user-facing strings. Tooltip or button labels carry meaning.

### Behaviors

#### Responsiveness

Icons scale via size tokens (`xs` through `xl`). Parent flex layout should not
squash below token dimensions.

### Edge cases

- **Invalid icon name** — component returns `null` and logs available names in development.
- **Suspense boundary** — SVG loads asynchronously; brief empty frame possible on slow networks.

## Accessibility

### ARIA roles & attributes

Kaizen sets `role="img"` and `aria-label={icon}` using the internal icon name.
For user-facing labels, wrap the icon in a labeled button or pass visible text.

### Screen reader behavior

Standalone icons announce the internal icon key (e.g. `trash-01`), which may not
match user language — prefer visible labels on interactive controls.

### Focus management

Icons are not focusable unless wrapped in an interactive parent.

### WCAG criteria

- **1.4.3 Contrast (Minimum)** — when icons convey information, ensure parent text color meets contrast.
- **4.1.2 Name, Role, Value** — interactive icons need an accessible name on the control.
