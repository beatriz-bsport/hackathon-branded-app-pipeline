# Alert

## Description

The **`alert`** component informs users that something important has happened, notify them of a success or failure or to take action.
We use this component when users need to be made aware of certain content.

### Strong

#### Usage

An alert with a strong, attention-grabbing appearance. This style is designed for important messages that require immediate user attention.
It uses strong colours and high contrast to ensure the alert is noticed promptly.
