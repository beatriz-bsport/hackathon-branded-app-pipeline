# TextField

## Description
The **`textField`** component is a standard input field where users can enter textual information. It is versatile and can be used for various types of textual input.

### Usage
Use for capturing names, addresses, email addresses, or any other textual information.
There are several optional states that can be added to display various things (required, error, disabled, caption, clear button)
