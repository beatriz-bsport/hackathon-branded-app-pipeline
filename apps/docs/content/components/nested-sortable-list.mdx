## Overview

Extends [Sortable list](/components/sortable-list) for grouped lists — reorder
within a group or drag items between groups. Built for shallow admin configuration
(one nest level), not member-facing navigation.

## Guidelines

<DoDont>
  <Do caption="Label each group clearly — users need predictable drop targets." />
  <Do caption="Confirm the API supports parent change, not just index within a group." />
  <Dont caption="Deep trees — keep nesting shallow; flatten IA beyond two levels." />
  <Dont caption="Member-facing flows that rely on precision drag between columns." />
  <Do caption="Explain in copy when dragging across groups changes category membership." />
</DoDont>
