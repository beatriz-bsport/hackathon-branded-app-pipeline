# Tooltip

## Description 

The `Tooltip` component is used to display informative text when users hover over an element. 

### Positioning

Follows the Menu component positioning logic. It's positioned relative to the children component
of the tooltip. 

It can be customized thanks to the properties `anchorOriginHorizontal`,  `anchorOriginVertical`, `transformOriginHorizontal` and `transformOriginVertical` 
Some positions are showcased below but you can customize it even in more to get the position you want.

### Coloring 

Two options for coloring are provided, the `default` also label as `weak` and `strong`.
It's also possible to override those colors by providing the `className` prop.
