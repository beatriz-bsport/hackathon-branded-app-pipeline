# Temporary Folder - Custom CSS-only Fields

This folder contains custom CSS-only fields designed specifically for our Custom Forms, such as the Sign-Up form. These fields serve as an alternative to Material-UI (MUI) components when the user opts for the 'Css only variant.'

## Temporary Naming

The folder is currently named 'Temporary' as a placeholder to signify its provisional nature. This naming convention is temporary and subject to change in the future.

### Reasoning
The 'Temporary' naming convention was adopted to quickly identify and segregate this collection of custom CSS-only fields as an interim solution. It serves as a placeholder until a more definitive and descriptive name is determined based on clear usage patterns, refinement of functionality, and feedback from implementation.

### Future Updates
As our team gains a better understanding of the usage, purpose, and unique characteristics of these custom CSS-only fields, we intend to rename this folder to reflect its definitive role within our application. This will involve identifying a more appropriate and descriptive name that accurately represents the contents and purpose of these specialized form components.

Please note that while the folder is currently labeled 'Temporary,' it functions as an integral part of our form system, providing an alternative field variant for our users.

## Overview

### Purpose
The purpose of this folder is to provide a set of specialized form fields that rely solely on CSS for styling. These fields are intended to offer an alternative visual representation to the MUI components typically used in our forms.

### Usage
In our application's form implementation, users have the option to select between default MUI components and these custom CSS-only fields. When the 'Css only variant' is chosen, the fields within this folder will replace the standard MUI components in the form.

## Folder Structure

### Components
The 'Temporary' folder includes various custom CSS-only field components designed to mimic the functionality of their MUI counterparts. These components can be seamlessly integrated into our Custom Forms.

### Integration
To use these CSS-only fields:
1. Identify the desired field in the 'Temporary' folder.
2. Import the necessary component(s) into the form file.
3. Implement the field in the form structure.
