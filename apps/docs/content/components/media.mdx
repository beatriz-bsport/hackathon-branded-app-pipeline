## Overview

Media displays photos and cover images with consistent rounding and aspect ratio.
While the image loads, it **fades in** from transparent to visible — there is no
skeleton or placeholder during download. Empty or broken sources render a neutral
placeholder with icon instead. Use for pass covers, venue photos, and marketing tiles
instead of raw `img` tags.

### Behaviors

#### Responsiveness

`object-cover` crops to the ratio box. Parents control width; height derives from
aspect ratio tokens.

### Edge cases

- **Empty src** — placeholder renders immediately.
- **Broken URL** — onError shows placeholder; offer re-upload in product UI.
- **Slow load** — image stays transparent until loaded, then opacity animates to visible;
  no in-component skeleton.

## Accessibility

### ARIA roles & attributes

Uses native `img` with required `alt`. Placeholder state has no image — ensure
adjacent text explains missing media.

### Keyboard navigation

### Screen reader behavior

Announces `alt` when image loads. Empty placeholder should not pretend to be
meaningful content.

### Focus management

When Media is the sole content of a clickable card, focus stays on the card wrapper.

### WCAG criteria

- **1.4.3 Contrast (Minimum)** — text on top of images needs scrim or placement outside the photo.
- **1.1.1 Non-text Content** — meaningful `alt` for informative images.
- **4.1.2 Name, Role, Value** — interactive wrappers name the destination.

## Improvements

### Loading state

During slow loads the image stays transparent until `onLoad` — no skeleton or weak-surface
placeholder behind it. Grids that need layout stability may need a parent skeleton until
the image appears. Track in
[KAI-856](https://linear.app/bsport/issue/KAI-856/kz-improvement-add-loading-placeholder-to-media).
