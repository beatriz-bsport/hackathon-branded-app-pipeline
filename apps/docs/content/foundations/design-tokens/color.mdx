Design tokens are a tech-agnostic way to store visual variables. Kaizen ships
them through `@bsport/kaizen-tokens`, which emits CSS variables and a Tailwind
theme. Components should consume **semantic** tokens (below), not raw palette
steps.

## Semantic colors

Each row shows a resolved swatch, a short description, and the CSS variable
to copy into product code.
