## Selector

### Description

The **`selector`** component presents users with a list of options, allowing them to choose one. It is commonly used for dropdown menus or selection lists.

### Properties:

- **captionText:** Text to display at the bottom of the selector.
- **children:** The options you want to display inside the menu. Usually MenuItems or MenuItemLists.
- **className:** Override or extend the styles applied to the component.
- **getSelectedItemLabel:** Callback function to extract the value we want to display in the selector from an item.
- **getSelectedItemValue:** Callback function to extract the value from an item. This value will be used to remove a selected item.
- **id:** The id of the selector.
- **isDisabled:** If true the element is disabled.
- **isError:** If true, the element will indicate an error.
- **isSelectorWidthControlledByRef:** If true, the selector will fit the width of the element used as ref.
- **isRequired:** If true, this field is required.
- **label:** Represents the selector label.
- **leftIcon:** The icon displayed on the left of the selector.
- **menuId:** The id of the menu.
- **multiple:** Boolean - allows users to choose more than one option from the list.
- **onRemoveItem:** Callback fired when clicking on the chip's clear icon button.
- **onClear:** Callback fired when clicking on the clear icon button.
- **placeholder:** Text to display as the default option when nothing is selected.
- **selectedItems:** The value(s) represented in the selector input.
- **size:** **`sm`** (small), **`md`** (medium)

### Usage
Ideal for presenting a list of categories, countries, or any other options for users to choose from.
Provides a structured way for users to make selections from predefined options.
