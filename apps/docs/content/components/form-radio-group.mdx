## Overview

Form radio group presents mutually exclusive choices with form-ready labeling,
helper text, and error display. It wraps [Radio](/components/radio) patterns for
settings where exactly one option must be selected — billing interval, visibility
mode, or default payment method type.

### Use cases

- **Pricing interval** — monthly vs annual on subscription setup.
- **Visibility rules** — public vs members-only on pass configuration.
- **Refund policy** — exclusive choices on cancellation settings.
- **Delivery format** — digital vs physical where only one applies.
- **Form sections** — paired with [Form](/components/form) schema validation.

## Guidelines

- **Exactly one selection** — enforce at form validation layer.
- **Visible labels** — every option has readable text, not color alone.
- **Default thoughtfully** — pre-select the safest or most common option.
- **Helper per option** — use secondary text for consequences of each choice.
- **Vertical list** — default layout; horizontal only for two short options.

### Best practices

#### General

<DoDont>
  <Do caption="Explain consequences in helper text under each option when choices affect billing." />
  <Do caption="Disable the whole group when the setting is locked, with reason in page Alert." />
  <Do caption="Keep option count small — split into another step if more than five." />
  <Dont caption="Radio groups for multi-select — use Checkbox group." />
  <Dont caption="Changing selection without warning when it triggers destructive side effects." />
  <Dont caption="Options that are really navigation — use Tabs or links." />
</DoDont>

### Behaviors

#### Persistence

Selection persists in form state until submit or reset.

### Edge cases

- **No default** — require explicit selection before submit when no safe default exists.
- **Dynamic options** — reset selection if options list changes and value is invalid.

## Accessibility

### Screen reader behavior

Announces group name, option label, and selected state.

### Focus management

Focus follows selected radio when using arrow keys in many browsers.

### WCAG criteria

- **2.1.1 Keyboard** — select without pointer.
- **3.3.2 Labels or Instructions** — group and option labels.
- **4.1.2 Name, Role, Value** — selected state exposed.
