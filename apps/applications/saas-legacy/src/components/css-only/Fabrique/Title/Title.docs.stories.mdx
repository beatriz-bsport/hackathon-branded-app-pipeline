# Title

## Description

The **`title`** component is used to display a title and a subtitle.

## Properties:
- **variant:** The variant of the title: `lg`, `md`, `sm` or `xs`.
- **isCollapsable:** If `true`, the title div will be collapsable.
- **title:** The title to be displayed.
- **subtitle:** The subtitle to be displayed.
- **childrenCollapsable:** The content to be displayed in the collapsable.
