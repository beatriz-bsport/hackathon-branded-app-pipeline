## Overview

Filter renders a horizontal bar of filter categories and applied values as
[Chip](/components/chip) tokens. Users add constraints from dropdowns, see active
filters at a glance, and reset the set. It targets Studio Manager list pages —
members, passes, sessions — not global search.

## Guidelines

<DoDont>
  <Do caption="Persist filters in the URL so refresh and share links keep context." />
  <Do caption="Remove one chip at a time via dismiss on the chip." />
  <Do caption="One reset control clears all active filters." />
  <Dont caption="Filters that do not affect the list — every chip must trigger query." />
  <Dont caption="Reset that also clears unrelated search text without warning." />
  <Dont caption="Twenty categories without grouping — split into advanced panel." />
</DoDont>
