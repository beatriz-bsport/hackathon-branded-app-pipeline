Kaizen uses [Untitled UI Icons](https://www.untitledui.com/free-icons) as its
source. Visual sizing rules and usage guidance for icons in UI will be
documented here.

For the developer workflow — adding SVGs to Kaizen, regenerating the registry,
and consuming icons in product code — see
[Icons](/foundations/icons) under **Reference**.
