# Bottom Drawer

## Description
A **`bottomDrawer`** slides in from the bottom of the screen. 
It provides an intuitive way to display additional content, options, or actions without taking up the entire screen space. 
The Bottom Drawer is often used for supplementary tasks, contextual information, or modal interactions.
