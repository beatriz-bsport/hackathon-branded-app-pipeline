## Overview

Radio groups present a labelled set of options where only one can be selected.
Use them when every option should stay visible and the list is short enough to
scan — typically two to five choices. For longer lists or search, use
[Select](/components/select) or [Autocomplete](/components/autocomplete).

Kaizen ships two variants:

- **RadioGroup** — general-purpose group; supports nested content under a selected
  option (`children`, `forceDisplayChildren`).
- **FormRadioGroup** — form-ready group with shared label, per-option helper text,
  and error display — billing interval, visibility mode, default payment method.

Cross-field label, helper, and error patterns live in
[Shared form guidelines](/components/shared-form-guidelines).

## Guidelines

<DoDont>
  <Do caption="Stack options vertically in forms so labels are easy to scan." />
  <Do caption="Use option `children` (RadioGroup) or `element` (FormRadioGroup) for fields that only apply to one choice — address fields under 'Ship to member'." />
  <Do caption="Explain consequences in helper text under each option when choices affect billing." />
  <Do caption="Disable the whole group when the setting is locked, with reason in page Alert." />
  <Do caption="Per-option errors — pass `errorText` on an option to highlight a specific row after validation." />
  <Dont caption="Multi-select belongs on Checkbox, not Radio." />
  <Dont caption="Horizontal radio rows to save space — use Toggle button for compact exclusive choice." />
  <Dont caption="Ten or more options without grouping overwhelm the form — switch to Select." />
</DoDont>

<Callout type="info" title="Horizontal layout">

Stack options vertically in forms. When space is tight and labels are short, use
[Toggle button](/components/toggle-button) for horizontal exclusive choice — not
a horizontal radio row.

</Callout>

### Behaviors

**RadioGroup** — controlled via `value` and `onChange`. Option `children` render
when `value === option.value` unless `forceDisplayChildren` is true. Each option
`value` must be unique within the group.

**FormRadioGroup** — reset selection if the options list changes and the current
value is invalid. Require explicit selection before submit when no safe default
exists.
