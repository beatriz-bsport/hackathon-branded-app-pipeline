## Overview

Text area collects multi-line plain text — class descriptions, email bodies,
internal notes, and comment fields. Field anatomy matches
[Text field](/components/text-field).

## Guidelines

<DoDont>
  <Do caption="State character limits in helper text when the API enforces max length." />
  <Do caption="Use read-only mode for displayed long text that must not edit inline." />
  <Do caption="Preserve line breaks users type for notes and descriptions." />
  <Dont caption="Tiny two-row text areas for content that routinely exceeds five lines." />
  <Dont caption="Rich formatting expectations without a rich editor." />
  <Dont caption="Single-line data — names and emails belong in Text field." />
</DoDont>

## Reference

### Props

<PropsTable component="TextArea" />

Grows with content when resize is allowed; parent can set `rows` or max-height.
Enforce `maxLength` at the form layer if the backend limits size.
