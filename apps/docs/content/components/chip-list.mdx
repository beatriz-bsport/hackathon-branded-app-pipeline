## Overview

Chip list displays multiple [Chip](/components/chip) tags in a row, collapsing
overflow into a "+N" popover when count exceeds `maxDisplay`. Use for member tags,
filter summaries, and multi-value fields in read-only detail views.

### Use cases

- **Member tags** — show first seven tags on profile header.
- **Applied filters summary** — read-only chip row in report headers.
- **Product labels** — color-coded chips on pass detail.
- **Team roles** — multiple role chips on staff cards.
- **Dismissible tags** — removable filters when chips are dismissible.

## Guidelines

<DoDont>
  <Do caption="Sort chips by importance so the most critical tags stay visible." />
  <Do caption="Use dismissible chips only when removal immediately updates data." />
  <Do caption="Match maxDisplay to column width in table cells." />
  <Dont caption="Chip list as the only way to see all tags — overflow must be discoverable." />
  <Dont caption="Mixing chip sizes in one list." />
  <Dont caption="Twenty visible chips without overflow — use compact summary link." />
  <Do caption="maxDisplay default 7 — tune per layout width." />
  <Do caption="Consistent chip props — type, color, size uniform within one list." />
  <Do caption="Overflow popover — clicking +N reveals hidden chips in `Popover`." />
  <Do caption="Disabled state — entire list non-interactive when context is read-only." />
  <Do caption="Editing tags — use `Tag input` or autocomplete for entry; Chip list for display." />
</DoDont>

### Behaviors

#### Dismissal

Dismissible chips call parent `onClick` per chip; list does not auto-compact until parent updates items.

### Edge cases

- **Fewer than maxDisplay** — no overflow control.
- **Empty list** — render nothing or parent empty state.

## Accessibility

### ARIA roles & attributes

Overflow trigger needs accessible name ("Show 3 more tags"). Popover traps focus per Popover rules.

### Keyboard navigation

### Screen reader behavior

Announce overflow count on trigger; list full set in popover.

### Focus management

Return focus to overflow trigger when popover closes.

### WCAG criteria

- **2.1.1 Keyboard** — reach overflow and dismiss actions.
- **4.1.2 Name, Role, Value** — overflow button named.
