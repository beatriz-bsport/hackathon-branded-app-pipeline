## Overview

Sidebar is the persistent left rail in Studio Manager for global wayfinding —
modules, search, notifications, and account utilities. It pairs with feature-internal
[Navigation](/components/navigation) in the top bar; see also [App navigation](/components/app-navigation) for the full shell model.

### Use cases

- **Module switcher** — jump between Booking, CDP, Finance, Marketing.
- **Global search entry** — open command palette or search overlay.
- **Notifications** — bell with [Indicator](/components/indicator) count.
- **Quick create** — shortcuts to add member or sale where product allows.
- **Account and settings** — profile, help, logout grouped at bottom.

## Guidelines

- **One global hierarchy** — do not duplicate feature tabs from the top bar.
- **Collapse on narrow widths** — icon-only mode with tooltips when space is tight.
- **Active module clear** — highlight current module; sub-routes live in top navigation.
- **Bottom utilities** — settings and account visually separated from product modules.
- **Consistent order** — modules follow product IA; avoid per-studio reorder without flag.

### Best practices

<Callout type="warning" title="Caution">

Sidebar and top navigation divide responsibility — duplicating Clients sub-tabs in both rails confuses spatial memory.

</Callout>

#### General

<DoDont>
  <Do caption="Keep high-traffic modules in the primary stack with stable icons and labels." />
  <Do caption="De-emphasize settings and logout in a bottom group separated by spacing." />
  <Do caption="Show active state on the current module even when a child route is open." />
  <Dont caption="Deep flyout trees in the sidebar — use top bar for sub-features." />
  <Dont caption="Feature-specific filters in the global sidebar." />
  <Dont caption="Hiding logout or account behind undocumented gestures." />
</DoDont>

### Behaviors

#### Responsiveness

Collapses to icons; expand control restores labels.

#### Persistence

Active module follows router state; collapse preference may persist per user.

### Edge cases

- **Federated modules** — loading state while remote nav chunk loads.
- **Permission-gated items** — hide or disable modules user cannot access.

## Accessibility

### ARIA roles & attributes

Navigation landmark (`nav`) with list of links; current page `aria-current="page"`.

### Keyboard navigation

### Screen reader behavior

Announce module name and current state; skip redundant "logo" links without label.

### Focus management

Route change may move focus to main content — follow app shell convention.

### WCAG criteria

- **2.4.1 Bypass Blocks** — skip link to main content alongside sidebar.
- **2.4.8 Location** — highlight current module.
- **4.1.2 Name, Role, Value** — link names describe destinations.
