## Overview

Dropdown multi select packs many optional values into one dropdown — tags, coaches,
locations — without consuming vertical form space. Selected values summarize in the
trigger label or chip count; the panel uses checkbox [Menu](/components/menu) items.

### Use cases

- **Filter by coaches** — multi-coach session reports.
- **Member tags** — assign multiple tags on profile edit.
- **Export columns** — choose many fields in export dialog.
- **Notification audiences** — segment multi-select in campaign setup.
- **Venue filter** — locations facet with many options.

## Guidelines

- **Summary in trigger** — show count or first label + "and N more".
- **Apply vs immediate** — immediate toggle for filters; Apply button when API batch is expensive.
- **Search inside panel** — for option lists longer than one screen.
- **Select all** — optional shortcut for bulk enable with indeterminate parent checkbox.
- **Clear selection** — one action resets all values.

### Best practices

#### General

<DoDont>
  <Do caption="Show how many options are selected in the closed trigger." />
  <Do caption="Keep option labels parallel and scannable inside the menu." />
  <Do caption="Disable the control when no options exist and explain why." />
  <Dont caption="Mutually exclusive choices in multi-select — use Select or Radio." />
  <Dont caption="Hiding selected values entirely when closed — users forget active filters." />
  <Dont caption="More than 50 options without search." />
</DoDont>

### Behaviors

#### Persistence

Value array controlled by parent; closing menu does not discard pending state if Apply pattern is used.

### Edge cases

- **All selected** — trigger may show "All" vs count — pick consistent pattern.
- **Single option** — consider checkbox vs disabled select.

## Accessibility

### ARIA roles & attributes

Trigger `aria-expanded`; menu items expose `aria-checked` for checkboxes.

### Keyboard navigation

### Screen reader behavior

Announce selection count changes when menu closes or Apply is pressed.

### Focus management

Return focus to trigger on close.

### WCAG criteria

- **2.1.1 Keyboard** — full selection without pointer.
- **4.1.2 Name, Role, Value** — checked state on items.
