## Overview

Autocomplete pairs a [Text field](/components/text-field) with a filtering
popover. Staff type to narrow members, activities, products, or tags — faster
than scrolling a long [Select](/components/select). It supports single and
multi-select, local filtering, debounced remote search, and chip display for
multiple values.

Prefer `AutocompleteControlled` for new code — standard `value` / `onChange`
on selected ids.

## Guidelines

<DoDont>
  <Do caption="Use `description` on items for secondary context — email under member name." />
  <Dont caption="Two fixed options are simpler with Radio or Select." />
  <Dont caption="Hiding chips without another summary leaves users without a record of selections." />
</DoDont>

<Callout type="warning" title="Caution">

Clearing the text field in single-select mode does not always deselect the
value — handle `onClear` explicitly until
[KAI-588](https://linear.app/bsport/issue/KAI-588) lands.

</Callout>

### Props

<PropsTable component="Autocomplete" />

Key configuration:

- **`multiSelect`** — `false` closes on pick; `true` keeps popover open and shows chips
- **`searchMode`** — `local` filters `items`; `remote` refreshes via `onValueChange`
- **`clearOnSelect`** — empties input after each pick for quick-add lists
- **`debounceValue`** — throttles remote `onValueChange`
- Validation flows through `textfieldProps` (`status`, `statusText`, `helperText`)

Popover closes on single-select pick, `Escape`, or click outside. Multi-select
stays open after each pick. Clearing the input does not clear selection.
