## Overview

List item (`List.Item`) renders one row inside [List](/components/list): primary
title, optional description, avatar or icon, chips, color stripe, checkbox selection,
and action buttons or overflow menu. It is the workhorse row pattern across Studio Manager.

### Use cases

- **Member row** — avatar, name, membership chips, navigate to profile.
- **Buyable line** — price in `rightTitle`, category color stripe.
- **Selectable import row** — checkbox with disabled state for locked items.
- **Session row** — coach avatar, time chips, compact mode in side panels.
- **Custom node** — `customNode` for rare layouts not covered by defaults.

## Guidelines

- **One primary title** — `title` is the main scan line; `rightTitle` for meta (price, date).
- **Description optional** — second line only when it adds non-obvious context.
- **Max three chips** — type system allows up to three; overflow visually clutters.
- **Actions split** — visible buttons for primary; `dropdownConfig` for overflow.
- **Link vs click** — `link` for navigation; `onItemClick` for selection without route change.

### Best practices

#### General

### Behaviors

#### Action button

Buttons fire independently; row `link` wraps navigable hit area per withLink helper.

#### Responsiveness

`compactMode` reduces padding and avatar size.

### Edge cases

- **disabled + checkbox** — prevent selection with explanation in parent.
- **chipsDirection** — `start` vs `end` alignment for RTL and layout balance.

## Accessibility

### ARIA roles & attributes

Row is `li` inside list. Checkbox labels should include row title.

### Screen reader behavior

Row accessible name should combine title and critical chips when needed.

### Focus management

Link rows receive focus ring on navigable wrapper.

### WCAG criteria

- **2.1.1 Keyboard** — row interactions without pointer-only targets.
- **4.1.2 Name, Role, Value** — checkbox and link names include row context.
