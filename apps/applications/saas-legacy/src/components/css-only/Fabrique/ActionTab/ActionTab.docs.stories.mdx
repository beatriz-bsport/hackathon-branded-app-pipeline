# ActionTab

## Description
The **`action tab`** component that acts as filter or sub-tab and allows users to select different views, statuses or pages.
It provides an interactive and visually appealing way to navigate and filter content.

## Usage
Use the **`action tab`** component to enable users to switch between different pages or filters while providing them with a clear visual indicator of the active selection.
Ideal for navigation menus, filtering options, or any scenario where users need to choose specific categories or views.
