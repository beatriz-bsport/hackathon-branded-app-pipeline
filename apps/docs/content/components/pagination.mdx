## Overview

Pagination is a **private primitive**. Product code wires it through
[paginationProps on List](/components/list) or
[paginationProps on Table](/components/table) — do not import it directly.

The bar shows an optional rows-per-page selector, a range summary, and page
navigation (first, previous, numbered pages with ellipsis, next, last). The
parent owns fetching: pass the current page slice in rows and keep
`totalItems` in sync with the backend.

## Guidelines

- **Parent owns data** — changing page or rows per page triggers a new fetch; Pagination does not slice rows.
- **Hide on single page** — page controls render only when `totalPages > 1`.
- **Match backend totals** — `totalItems` must reflect the server count, not the current slice length.
- **Reset on filter change** — jump to page 1 when filters or search change materially.

#### General

### Behaviors

#### Data flow

List and Table render Pagination when `paginationProps` is set. Callbacks
(`onPageChange`, `onRowsPerPageChange`, or combined `onPageSettingsChange`) notify
the parent to fetch and pass updated rows.

#### Persistence

Page index and rows-per-page preference are consumer concerns — URL query params
or store state for back-navigation recovery.

#### Responsiveness

Below the `sm` breakpoint, `maxVisiblePages` defaults to 6 and the rows selector
is hidden. Pass `maxVisiblePages` to override on any breakpoint.

### Edge cases

- **Page numbers above 999** — button labels shorten to `..XX`; tooltip shows the full page number.
- **Current page out of range** — component clamps to the nearest valid page via callback.
- **Empty page after delete** — parent should move to the last valid page; clamping handles stale indices.
- **Invalid totals** — returns null when `totalItems <= 0` or `rowsPerPage <= 0`.

## Accessibility

### ARIA roles & attributes

First, previous, next, and last controls are icon buttons with visible labels passed
as `aria-label` (e.g. "Previous page"). Each page number button sets
`aria-label="Page N"`. The active page is styled visually; there is no
`aria-current="page"` attribute today.

### Screen reader behavior

Icon navigation buttons announce their label on focus. Abbreviated page labels
(above 999) still expose the full page number in `aria-label`.

### Focus management

Focus stays on the control that triggered the page change. Optionally move focus
to the list or table heading after a page change on long views.

### WCAG criteria

- **2.1.1 Keyboard** — all controls reachable and activatable without a pointer.
- **4.1.2 Name, Role, Value** — every control has an accessible name.
