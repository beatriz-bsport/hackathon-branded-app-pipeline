## Overview

Indicators are non-interactive signals anchored to a host — they have no meaning without it.

Indicator is a non-interactive, non-dismissible signal that draws attention to a specific location. It is always anchored to a host element like a button, avatar, or nav item. It comes in sizes sm and md with colors default, main, critical, success, warning, and info.

### Choosing between Badge, Chip, and Indicator

| Aspect           | Badge                  | Chip                                     | Indicator                     |
| ---------------- | ---------------------- | ---------------------------------------- | ----------------------------- |
| Purpose          | Supplementary metadata | Semantic token (tag/filter/status)       | Attention/notification signal |
| Dismissible      | No                     | Yes (optional)                           | No                            |
| Anchored to host | No                     | No                                       | Yes (top-right/bottom-right)  |
| Typical use      | Side labels            | Tags, filters, categories, object status | Counts, status dots           |
| Appearance       | Text in a pill         | Container with label (and optional icon) | Dot or numbers                |

Use Indicator for non-dismissible status signals anchored to a UI element — for example, an unread notification dot on an avatar or an active status dot on a profile picture. It relies on color and placement rather than text labels.
