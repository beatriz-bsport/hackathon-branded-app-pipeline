## Overview

Date picker lets users choose one date or a range with calendar UI, shortcuts, and
disabled-date rules. It supports modal dialogs for mobile-like flows and popover
anchoring for dense filter bars in Studio Manager.

### Use cases

- **Report date range** — finance exports for last 30 days or custom interval.
- **Class schedule** — pick session date on booking forms.
- **Member birth date** — single date with past-only constraint.
- **Campaign send window** — range with shortcuts (This week, Next month).
- **Filter toolbar** — popover variant on list pages.

## Guidelines

<DoDont>
  <Do caption="Show the selected value in the trigger even when the calendar is closed." />
  <Do caption="Use range mode when both start and end matter for reports." />
  <Do caption="Disable dates the backend will reject before submit." />
  <Dont caption="Free-text date parsing without picker — error-prone across locales." />
  <Dont caption="Range pickers for a single moment in time — use single mode." />
  <Dont caption="Opening modal pickers inside modals without focus trap review." />
  <Do caption="Modal vs popover — modal for primary form fields; popover for inline filters." />
  <Do caption="Disable invalid dates — block past dates for bookings or future-only promos." />
  <Do caption="Shortcuts reduce taps — offer presets for common reporting windows." />
  <Do caption="Locale and timezone — display dates in studio locale; store ISO in API layer." />
  <Do caption="Label the field — always pair with visible label showing selected value." />
</DoDont>

### Behaviors

#### Dismissal

Popover closes on outside click or selection depending on configuration; modal uses explicit apply.

#### Responsiveness

Modal layout suits narrow viewports; popover anchors to trigger width.

### Edge cases

- **Partial range** — guide users to complete end date before apply.
- **Year bounds** — customize min/max year for birth dates vs reporting.

## Accessibility

### ARIA roles & attributes

Calendar grid should expose day buttons with `aria-selected` and navigable month controls.

### Keyboard navigation

### Screen reader behavior

Announce selected dates on apply; live region optional for range completion.

### Focus management

Return focus to trigger on popover close; trap focus in modal variant.

### WCAG criteria

- **2.1.1 Keyboard** — date selection without pointer-only interaction.
- **3.3.2 Labels or Instructions** — label shows format expectations.
- **4.1.2 Name, Role, Value** — selected date in accessible name.
