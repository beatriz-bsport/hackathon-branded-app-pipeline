## Overview

Checkboxes support multi-selection in forms, filters, and lists where options are independent.

##### Related Components

- _Checkbox:_ Used when multiple selections are allowed.
- _Toggle Switch:_ An alternative for binary options, often used for settings.

### Best practices

- Use checkboxes for multi-selection when users can choose multiple options independently.
- Always provide a default state (checked or unchecked) that aligns with user expectations.
- Use a disabled state when an option is unavailable but should remain visible.
- When using a group of checkboxes, align them vertically for readability.
- Implement `intermediate` state for checkboxes representing groups of sub-options.
