# DatePicker

## Description
The **`date picker`** component is a **`Menu`** component containing a calendar that allows the user to pick a date.

### Usage
Thanks to it's verstalitiy, the **`date picker`** component can be used inside any context where the user need to set or use a date (filters, date field, etc...)

### Enable past
When **`enablePast`** is set to true, the user can select dates from the past.
