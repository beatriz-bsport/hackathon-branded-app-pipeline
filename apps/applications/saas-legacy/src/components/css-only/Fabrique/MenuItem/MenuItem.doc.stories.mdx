# MenuItem

## Description

The **`MenuItem`** item populates dropdown with actions. Items can be placed either inside a group or directly inside a **`Menu`** component.

###

## Usage

Group **`MenuItem`** items into **`MenuItemList`** based on related categories.

### Text/text with icon

#### Usage

- **Button** - does a desired function (ex.: cancels a session; confirms/cancels the dialog).
- **Link** - redirects the user to another page.
