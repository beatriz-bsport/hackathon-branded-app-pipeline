## Overview

Checkbox group renders multiple [Checkbox](/components/checkbox) options under one
logical field — permissions, week-day toggles, or multi-select filters. It supports
declarative option lists and composable children for custom layouts.

## Guidelines

<DoDont>
  <Do caption="Keep option labels parallel — each starts with the same grammatical form." />
  <Do caption="Show indeterminate parent checkbox when implementing select-all patterns." />
  <Dont caption="Mutually exclusive choices — use Radio group instead." />
  <Dont caption="More than eight options without search — consider multi-select dropdown." />
  <Do caption="Vertical stack default — horizontal only for short binary pairs." />
  <Do caption="Disable entire group when the feature is unavailable, with helper text explaining why." />
</DoDont>

### Edge cases
