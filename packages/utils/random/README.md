# Random utils

Package providing functions creating random strings based on different strategies.

## How to use

1. First add it by adding it in tthe dependencies of your `package.json`

   ```json
   {
     "dependencies": {
       "@bsport/random-utils": "workspace:*"
       // other dependencies...
     }
   }
   ```

2. Import any function from the package

   ```tsx
   import { uuid } from "@bsport/random-utils";

   // ...
   ```
