## Overview

TextField collects one line of user input — names, search queries, amounts,
emails, and other typed values. It supports prefixes, suffixes, icons, clear
actions, and validation status. Use [Autocomplete](/components/autocomplete)
when the user picks from suggestions; use [Text area](/components/text-area) for
multi-line copy.

## Guidelines

<DoDont>
  <Do caption="Use prefix or suffix for units — '€', 'kg' — instead of baking units into the label." />
  <Do caption="Pass `inputRef` when a modal should autofocus the first field on open." />
  <Do caption="Use `status='error'` with specific `statusText`; `status='positive'` sparingly for async validation." />
  <Dont caption="Positive feedback on every keystroke adds noise without aiding completion." />

### Input types

Set `type` to match collected data. Always validate on the server too.

- **`text`** — short free text
- **`password`** — masked entry; pair with `autocomplete` for password managers
- **`number`** — numeric values; optional `min`, `max`, `step`
- **`email`**, **`tel`**, **`date`**, **`datetime-local`**, **`time`** — typed formats with native keyboard hints
- **`search`** — toolbar queries; native clear hidden — use `onClear`
- **`color`** — hex colour entry with swatch UI

`status`: `default` | `positive` | `error`. Without `fullWidth`, max width is
`max-w-element-4xl`.
