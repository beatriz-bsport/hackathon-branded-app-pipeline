# Card

## Description

The **`Checkbox`** component allows users to select or deselect a single option. It is typically used when there are binary choices or when multiple selections are allowed.

## Usage

Suitable for yes/no questions, terms and conditions agreements, or any scenario where a single option needs to be chosen or unchosen.
