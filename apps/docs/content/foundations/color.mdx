Kaizen uses two layers of color tokens. The **base palette** holds the raw
hexes (`color.luna-grey.500`). Semantic tokens layer on top of the base palette
and reference it and are what components should consume. Reaching
into the base palette directly from product code is a smell.

## Base palette — Luna grey

The neutral scale anchors almost every UI surface. Lower numbers are
brighter; higher numbers are denser.

## Accent — Terra green

The Kaizen accent. Reserved for primary intent, success states, and
selection.

## Status — Cupid red

Red is reserved for critical/destructive intent. Don't use it for emphasis.

## How a single color resolves

Picking `color.luna-grey.500` from a component composes to a CSS variable,
which resolves to a concrete hex at build time. The token-alias chain
is the contract between design and code:

<TokenAlias from="color.luna-grey.500" />

You can also spot-check a single swatch inline:

<ColorSwatch token="color.luna-grey.500" value="#7f8786" />
