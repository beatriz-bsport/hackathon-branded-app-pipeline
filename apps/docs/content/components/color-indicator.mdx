## Overview

Color indicator renders a solid color sample as either a vertical line or a
rounded block. It encodes activity, category, or tag color beside labels in
lists, tables, and pickers — the swatch reinforces meaning that adjacent text
must already carry.

### Examples

- **Session calendar** — line stripe on table rows via [Table](/components/table) `row.color` (activity color from scheduling).
- **Activity picker** — line stripe on mobile list rows via [List item](/components/list-item) `color`.
- **Tag list** — line stripe on tag rows in CDP tag management via List item `color`.
- **Tag detail header** — block swatch beside the tag name on the detail page.
- **Tag pickers and filters** — block swatch in [Autocomplete](/components/autocomplete) or menu `leftSlot` / `rightSlot` (session form, segment filters).

### Edge cases

- **Invalid color string** — browser may ignore; validate hex on save in forms.
- **Transparent colors** — may disappear on weak surfaces; avoid alpha-only values.

## Accessibility

### ARIA roles & attributes

The component sets no ARIA attributes. When the swatch repeats information already
in visible text, pass `aria-hidden="true"` on the indicator. If color is the only
differentiator, add visible text or `aria-label` on the parent row or option.

### Screen reader behavior

Screen readers do not announce background color — the adjacent title must include
the category or tag name.

### Focus management

Not applicable.

### WCAG criteria

- **1.4.1 Use of Color** — require text labels alongside swatches.
- **1.4.3 Contrast (Minimum)** — swatch border against surface if needed for visibility.
- **4.1.2 Name, Role, Value** — row accessible name includes category text.

### Known issues

#### Implementation gaps

- **Local swatch duplicates** — level selectors (session, VOD) and the referral-program tag selector use inline div swatches instead of ColorIndicator; radius and size differ from the primitive.
- **Props table noise** — `sizeByType` appears in the generated table but is an internal CVA key, not part of the public API.
- **`aria-hidden` not built in** — decorative hiding is the consumer's responsibility; the component does not set it by default.
