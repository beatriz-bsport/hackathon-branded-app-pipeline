## Overview

Radio buttons form a mutually exclusive set — only one option can be selected at a time.

##### Related Components

- _Checkbox:_ Similar to a radio button but used when multiple options in a group can be selected.
- _Toggle Switch:_ An alternative to checkboxes for binary options, often used for settings.

### Best practices

- Use radio buttons when users must choose _one option_ from a predefined list.
- Ensure all options are clearly labelled and mutually exclusive.
- Always present radio buttons in a group—never use a standalone radio button.
- Apply the `has-error` and `error-text` properties to provide feedback when the radio button input is incorrect.
