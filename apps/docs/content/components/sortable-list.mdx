## Overview

Same row patterns as [List](/components/list), with a drag handle to reorder items.
Persist order on drop or via an explicit save — pick one strategy per flow.

## Guidelines

<DoDont>
  <Do caption="Show the drag handle only when the user can reorder." />
  <Do caption="Auto-save on drop or a Save button — not both." />
  <Dont caption="Drag reorder on paginated data — load the full ordered set first." />
  <Dont caption="Sortable rows mixed with fixed rows without visual distinction." />
  <Do caption="Offer move up/down actions as a keyboard alternative to drag." />
</DoDont>
