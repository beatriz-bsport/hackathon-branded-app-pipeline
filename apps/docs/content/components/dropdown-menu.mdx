## Overview

Dropdown menu opens a [Menu](/components/menu) from a trigger — overflow buttons,
filter pickers, and assignment fields. It handles placement, focus, optional quick
search, and composable APIs for custom item rendering.

### Use cases

- **Row overflow** — three-dot menu on table and list rows.
- **Assign coach** — searchable list of staff in session editor.
- **Export formats** — PDF vs CSV chooser on report headers.
- **Status change** — workflow transitions on member cards.
- **Multi-select filters** — composable API for checkbox menus.

## Guidelines

<DoDont>
  <Do caption="Use icon-only overflow triggers with aria-label Actions on each row." />
  <Do caption="Enable search when options exceed one screen of scrolling." />
  <Do caption="Align placement so menu does not cover the trigger label." />
  <Dont caption="Primary navigation entire modules from row dropdowns — use sidebar." />
  <Dont caption="Nested dropdowns more than one level deep." />
  <Dont caption="Destructive delete as first item without divider separation." />
  <Do caption='Trigger labels the menu — button text or `aria-label` ("Actions", "Choose coach").' />
  <Do caption="Search for long lists — enable quick filter above ~8 options." />
  <Do caption="Placement — flip when near viewport edge; avoid clipping in modals." />
  <Do caption="Composable vs managed — managed API for standard cases; composable for custom slots." />
  <Do caption="Close on action — single-select menus close after choice unless documented otherwise." />
</DoDont>

### Behaviors

#### Dismissal

Outside click, Escape, and item selection close the menu (mode-dependent).

#### Focus management

Focus trap inside open menu; return focus to trigger on close.

### Edge cases

- **Custom target** — ensure keyboard activation on non-button triggers.
- **Modal context** — verify z-index and focus trap interaction.

## Accessibility

### ARIA roles & attributes

Trigger uses `aria-expanded` and `aria-haspopup`. Menu items inherit Menu a11y.

### Screen reader behavior

Announce menu open state and item count when search filters results.

### Focus management

Focus first item or search on open; restore trigger focus on close.

### WCAG criteria

- **2.1.1 Keyboard** — full menu operation.
- **4.1.2 Name, Role, Value** — trigger and items named.
