# Coach Selector with Card


This `Coach Selector` allows to select a single coach and the coach replace the selector when selected.

### When no teacher is selected


<Canvas>

    name="NoTeacherSelected"
    args={{

        placeholder:"Select a coach",
        value:null,
    }}
  >
  {Template.bind({})}
  </Story>
</Canvas>
